# Studio photos, November 2026

32 real photographs (22 left here; 10 promoted, below) of the Tcules studio and team (Yash's starred Google Photos, 3 Nov 2026), for a
designer to pick from. They are **not in `catalogue.json`** and no page uses them: `photos:check` reads
only catalogued photos, so nothing here is gated until one is picked.

WebP, longest edge 2,400 px, named `studio-<scene>-<detail>`. Letters a/b/c/d are frames of the same
moment: pick one per set. No person is named; per `src/lib/photos.ts` these are atmosphere photos with
`alt=""`.

**To use one:** move it up into `public/kit/photos/`, add its `catalogue.json` entry, and run
`npm run photos:tone && npm run photos:derive` in the same PR (`npm run verify` fails otherwise).
