Home's "Where is your product today?" cards carry "eyebrow, title, links. that's it": the blue label,
the title, a `stack` (48) of air kept open for breathing room, then the ways in as ruled rows. No
description and no example. The head is left-aligned on tint, and the set closes on one row
(2026-11-05-cards-ask-closes-as-one-row), the ask a primary solid `md`: the owner's exception to
2026-10-07-blue-solid-is-the-one-main-action, carried over.

**Why.** Jatin on the built page: "ye bahut text hai yaar"; the descriptions were cut before launch. The
head was centred only because the button sat in the middle; with the close a row, the band reads left.

**The mistake it prevents.** The 4 Nov variant H cards, each with a two-line description between title
and ways in.

**How to apply.** HomePage `Situations` drops each path's words and example before GatewayPaths. The
copy still authors them, so the CMS may keep them; the page does not set them.
