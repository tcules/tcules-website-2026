Illustrations are left-facing (mirror the §4a projection): page content sits to the left, so screens and fronts face it. Sequences read left to right: first element furthest left, last furthest right, while still facing left.

**Why.** A drawing should turn towards the words it sits beside.

**The mistake it prevents.** Screens facing away from the page copy; sequences running right to left.

**How to apply.** Every illustration. Where a drawing accompanies something else, it faces that (the enquiry desk faces the form). ch05 §4a fixes the light, not the facing.
