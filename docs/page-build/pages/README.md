# Page records

One file per page (or per template, for a family like the 12 expertise pages), written in the same PR as the
page's design pass. It exists so the next page starts from what is settled: read the records of the pages
nearest to yours before designing, and reuse a mapping rather than re-deriving it.

Keep each record short. Shape:

```
# /route — status (designed, PR #n, date)

## Decisions
- One line each. Name the ruling (`decisions/…`) when there is one; an unlogged owner call says "owner, date".

## Band → component
| Band id | Kind / component | Arrangement and notes |

## Content mapping
- Where the copy was split, titled, reordered (form before FAQ) or pulled into a field, and the
  content-changes entry it needs, if any.

## Open
- What waits on content, a logo, a drawing or the owner.
```

A rule that would decide some other page's band belongs in `../treatment-rules.md` as well, not only here.
